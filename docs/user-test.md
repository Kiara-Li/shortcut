## Scenario

You know Figma and are editing a poster in Illustrator. You want to resize an object and duplicate it, but remember Figma’s shortcuts rather than Illustrator’s. Select the Figma → Illustrator relationship before the task.

With Shortcut running and Accessibility enabled, turn on Figma Mode. Press K to look up Scale, then use S to scale a selected object. Press Cmd+D, read the fixed right-side hint, then use Cmd+C followed by Cmd+F to duplicate. Continue working without opening details; then look up one action again and choose View details when you want its explanation. Turn the mode off and check that Illustrator's original shortcuts work again. Revisit one lookup under Saved. For the website, search for the same two actions and open their hints.

Additional implementation checks: O → L must select Illustrator's Ellipse tool rather than request a new Line hint. Check ordinary Cmd+C, canvas text/fields, Escape during an unfinished operation, repeated queries, pointer movement, a second display, and full-screen Spaces. Existing first-try achievements remain, but expanding rewards or History is outside this iteration.
